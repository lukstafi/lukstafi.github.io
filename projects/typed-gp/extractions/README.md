## Character decoding

The originals use TeXmacs 1.0.5.4 and an old byte encoding. The reading copies
were produced with this explicitly inferred mapping:

```text
8A → Ł    9B → Ż    A1 → ą    A2 → ć    A6 → ę
AA → ł    AB → ń    B1 → ś    B9 → ź    BB → ż
```

All other bytes were mapped to the Unicode character with the same numeric
value (including F3 → ó and FC → ü). This is a reading conversion, not a
complete implementation of the TeXmacs encoding. Residual escaped characters
remain. The `.txt` suffix is deliberate: these UTF-8 copies are not certified
TeXmacs documents. Open the originals in TeXmacs for editing or rendering.

## Mathematical fidelity

`dyplom4.approximate.txt` was generated by an ad hoc sequence of markup
substitutions, not a proper TeXmacs parser. Some formula fragments disappeared,
table formatting leaked into the text, and accents were sometimes incorrectly
labelled as vectors. It is useful for navigating the prose only. Do not use it
as authority for a definition, theorem, quotation containing mathematics, or
implementation. Check the original source markup, with the UTF-8 source copy
as a reading aid.

The original one-off extraction code was not saved as a standalone script.
Before undertaking a proof audit, build a reproducible conversion or obtain a
verified rendering, and compare representative formulas against the source.
