**Theorem.** Require one ground assignment to satisfy the answer and *all* ordinary premises. Continue to require $A\land D_i\Rightarrow C_i$ separately for each $i$. Without designated parameters, under any quantifier prefix, this problem is NEXP-complete on every fixed finite single-sorted signature with a branching constructor and a constant. A single common row and a term strategy of polynomial depth always suffice on a positive instance. Every nontrivial monadic signature gives NP-completeness. The lower bound for branching terms already has two compatible input-only premises and all universal moves before all existential moves. [Two-branch lower bound](round-46-two-observations.html)

The common assignment need not be supplied. If all variables are existential, the problem reduces to unifying the conjunction of every $D_i,C_i$. A ground solution itself gives a singleton answer. With a prefix, the answer must also admit moves at the other universal inputs. A counterexample to $C_i$ anywhere in $A\land D_i$ still invalidates the answer, even if another premise is false there.

## Use all the unification traces at the same row

Start from a successful public pattern and a common ground row $W$. Its universal coordinates are distinct bare parameters absent from earlier existential coordinates. Freeze every nuisance parameter at $W$. This leaves one term strategy $B$ respecting the prefix, preserves the common row, and preserves every branch's relevance by restricting the answer relation. Conversely a successful term strategy is itself a pattern answer. [Single-row specialization](round-20-one-branch.html#one-witness-determines-the-strategy-form)

Write $H$ for its independent inputs, $m$ for the number of branches, and $S$ for the ground values at $W$ of all public coordinates and all written subexpressions of all the branches. Fix at the root every value attained by an explicit constructor. The size $s=|S|$ is at most the input length. For each $i$ separately unify $D_i[B]$. Follow matching constructors to a first disagreement, bind the input there to the other subterm, substitute, and continue. The common witness means that every binding respects the same ground valuation. There are at most $m|H|$ pivots across these independent runs.

Along each pivot path record the segments between consecutive values in $S$. Pool these segments *by their starting ground value*, across all branches, into the selection plan of Round 28. At a fixed root retain the constructor and children. At any other selected value retain just the chosen subtrees in a fixed list context, or use the base constant if the list is empty. On an open term keep an input variable as itself. The lookup for a selected segment cannot cross an input leaf before its endpoint, since every input value belongs to $S$. The segments from one starting value are incomparable and a single pivot path visits that value at most once.

For any substitution $\rho$ respecting $W$ the same plan therefore satisfies $\pi(t\rho)=\pi(t)\widehat\rho$, where $\widehat\rho(h)=\pi(\rho(h))$. Apply this identity to each unification run in turn. At a ground assignment satisfying its shortened premise, decomposition along the retained paths forces that run's transformed bindings. Its mgu made its own conclusion an identity, so the transformed bindings do the same for the shortened conclusion. The fixed constructors make this exactly the original implication on the shortened strategy. No branch uses a binding from another branch. Applying the identity to the common ground assignment gives a common active row for the shortened strategy. [Compression and pivot replay](round-28-compression.html) · [Lean substitution identity](round-28-projection.lean)

Per distinguished value the resulting ground DAG uses $O(1+m|H|)$ nodes pointing to strictly smaller distinguished values. An open path visits at most $s$ of them, giving polynomial depth. On a fixed signature the explicit open terms have at most singly exponential size. Guess them and verify prefix scope, joint consistency by one unification, and relevance by a separate unification per branch. This takes nondeterministic exponential time. In a monadic signature polynomial depth already implies polynomial term size, giving NP membership. A single quantified implication supplies the NP lower bound. [One-branch hardness on monadic signatures](round-30-monadic.html)

With input-only premises that are jointly unifiable and a prefix $\forall H\,\exists Y$, standard prefix validity already guarantees common activation. The theorem consequently gives an exact complexity bound for this fragment of the original problem without any added acceptance test. The two-branch lower bound uses only flat equations. [Compatible input-only construction](round-46-two-observations.html)

## Other validity conventions

For trailing validity with the source's designated parameters, project out the substituted names as in Round 30 and append them as existential outputs. This preserves the public pattern and hence common activation. For leading validity with prefix-closed read permissions, first specialize fresh parameters at the common row. Solved presentations use the same path construction, with additional paths retaining the syntactic supports of their right sides and any required bare copies. This preserves the retained-universal criterion and both escape tests.

For arbitrary weak conjunctions, take the at most $|X|$ equivalent admissible primitives from Round 31 and record their occurrences for padding. First trace their mgu and then, **from that same mgu separately**, trace each $D_i$. Again every trace respects the common row. Include their pivot paths, the necessary occurrence paths and all branches' constructors in the plan. The initial trace preserves the free residuals and transforms the primitives' mgu coordinatewise, giving leading validity with closed reads. Each continuation proves its own relevance. The number of pivots and support paths remains polynomial. This gives the same NEXP upper bound on branching signatures and NP on monadic ones. With one forbidden read under the extracted weak rule, even a single branch is r.e.-complete on branching terms. The [checks](round-44-common-witness.py) pool the plans for 150 families of compatible premises and verify every compressed branch independently. One example requires two different paths through the same ground tree, each contributed by a different branch. The checker also rejects a conclusion obtained by mixing two branches' bindings.
