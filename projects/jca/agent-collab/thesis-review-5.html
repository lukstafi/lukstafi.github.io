A two-atom solution that requires one captured parameter

Write \(r\) for the recursive result and \(u\) for the next result. The external function requires the caller contract \(D\) and its result constructor guarantees \(E\).

\[ D(m,r)\equiv 0\le r\ \land\ r\le\max(m+20,0),\qquad E(m,r,u)\equiv 0\le u\ \land\ u\le r+1\ \land\ u\le\max(m+19,0). \]

For a function admitting every \(m\), the obligations for its result predicate \(R\) are

\[ R(m,0),\qquad R(m,r)\Rightarrow D(m,r),\qquad R(m,r)\land D(m,r)\land E(m,r,u)\Rightarrow R(m,u). \]

Taking \(R=D\) solves all three obligations. The base satisfies both inequalities. The step case follows from \(\max(m+19,0)\le\max(m+20,0)\). The resulting type is \(\forall m.\,\mathrm{Num}(m)\to\mathrm{Nat}\to\exists r\,[D(m,r)].\,\mathrm{Num}(r)\).

No relation on \(r\) alone can solve them. At \(m=0\), the base puts \(0\) in the relation. The step from \(0\) can produce \(1\), so the relation must contain \(1\). At \(m=-21\), the caller contract would then require \(1\le 0\). This rules out every parameter-free interpretation, of any size, for the unrestricted input scheme. Capturing \(m\) is sufficient. What happens at the jump

The original linear capped-climb already refutes convergence from a bound on solution size. Under the common-atom jump, pass 8 stores the valid band \(m\le r\le m+20\). On every later pass the suppliers return the stronger upper bound \(r\le m+19\). The jump drops the differing upper atom and the caller restores it. Table 4.4 requires the new caller contribution to be empty. The recurrence proves that this run never passes the stopping test, even when every stored predicate fits a constant bound. The repaired numeric checks apply the existing quantifier-order test to surviving extremum atoms after substitution. If the checked linear facts entail the atom, the requirement is discharged. Otherwise a restriction at a predicate-owned universal goes back to the splitter, and a forbidden restriction raises a quantifier violation. At the jump, the solver first tests the new summary against an old numeric atom. If the summary is too weak, it can test the atom against every projected numeric supplier branch that contributed to the generalization. Replay uses variables on the aligned public interface of both predicates. It requires a supplied family of branches and retains an atom only if all feasible branches entail it. Omitting a variable from a branch leaves that variable unconstrained in its implication test. For the start-at-\(m\) example the base proves the upper bound, and each recursive case proves either \(r\le m+19\) or \(r\le 0\). A convergence theorem with a fixed vocabulary

Fix the captured interfaces and the unary preconditions. For each postcondition, supply a finite set of candidate atoms over its public arguments. Let \(N\) count the atoms across all predicates, counting an atom separately at each predicate. A state \(X\) selects some of these atoms, interpreted conjunctively. Assume that recursive result predicates occur positively in the suppliers, and that making result predicates stronger preserves caller safety. These hypotheses allow mutual recursion. They exclude a changing parameter interface.

Start with every candidate atom. For each pass retain \(a\in X\) exactly when all its defining branches, instantiated with \(X\) at recursive uses, entail \(a\) at the supplied result. Include every base branch. Use the same state for all tests in a pass. Assume decidable, exact branch tests and keep atom identities fixed across passes. This is the elimination rule of Houdini applied to the binary postconditions of Table 4.4. The implemented jump rechecks existing atoms but obtains its starting formulas and interfaces from inference. Flanagan and Leino, Houdini, an Annotation Assistant for ESC/Java

Theorem. Within \(N+1\) passes, including a final verification pass, elimination finds the strongest conjunction in the pool closed under all suppliers. It satisfies every caller obligation if and only if some conjunction in the pool is closed and satisfies those obligations.

To prove it, take any closed candidate \(I\). Initially \(I\subseteq X\) as sets of atoms. Every recursive row admitted by \(X\) is then admitted by \(I\). Positivity means each supplier row obtained under \(X\) is also obtained under \(I\). Every atom of \(I\) therefore survives the pass. Induction keeps \(I\subseteq X\) throughout. Each changing pass deletes at least one atom. At stabilization every surviving atom holds on every supplier row, and all closed candidates are subsets of the surviving set. If any closed candidate makes the callers safe, the stronger surviving conjunction does too. Conversely a safe final conjunction is itself such a candidate. On a successful run the caller never needs to add an atom, since even the intermediate conjunction after each deletion still entails the successful candidate. Lean proof of stabilization, preservation and caller safety

This gives a bounded-size corollary for conjunctive postconditions on a known interface. For a bit bound \(b\), put every well-formed, predicate-tagged atom encodable in at most \(b\) bits in the pool. A solution of total encoded size at most \(b\) contributes all of its atoms. With the stated checks and monotonicity, the search succeeds on that promise. There are \(2^{b+1}-1\) binary strings of lengths zero through \(b\). The number of passes can therefore be exponential even when \(b\) is polynomial in the input size. The strongest returned conjunction can exceed \(b\). Deciding whether an answer itself fits \(b\) uses the bounded certificate search described in the previous review. Bounded verification

The implementation still has to discover that \(m\) belongs in the package. The start-at-zero program gives a test for any proposed capture rule. The rule has to identify the parameter at the definition and instantiate it with the corresponding argument at each recursive use. Carrying an incidental local variable with the same printed name would miss the distinction as soon as a recursive call changes \(m\).
