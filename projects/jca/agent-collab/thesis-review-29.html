A call can choose its own interval

The recursive function returns an integer in \([k,k+2]\). The caller may choose any \(k\) whose interval contains the supplier value \(4i+1\) at input state \(i\). Inside the recursive branch, the child call needs its own interval. Every value in that interval must miss the guard \([2,4]\). With states 0 and 1 the only possible child keys are \(-1\) and 5, respectively. InvarGenT now infers the single equation \(k_{\rm child}=6i-1\) and checks the program at an outer iteration budget of 2. Program · Uniqueness proof

After the ordinary guard checks fail, the compiler takes literal forbidden bands from the unresolved arms. It reads sample indices from constructors of the argument type and drops those incompatible with the written precondition. Suppose the package bounds its result between \(k+a\) and \(k+b\). Avoiding a band \([l,u]\) requires \(k\le l-b-1\) or \(k\ge u-a+1\). The compiler intersects those choices with the input bounds. When each sample leaves one finite interval of keys, it fits an integer slope and intercept using the pair inequalities below. It adds the proposed equation to the fresh instance at each recursive use. All original branches, calls and negative guards go through the checker again. The samples guide inference even when the datatype also has a constructor whose index varies. Executable checks

One client requires the result at state 0 to be at least 1. This forces its parent key to be 1, although its child must choose \(-1\). The client at state 1 requires a result at most 5 and forces parent key 3, although its child must choose 5. Both clients check and execute together. The emitted OCaml still calls run s d. A third state needs a different witness

Add a constructor with index 2. The supplier values now give the following choices after removing the forbidden band.

Input state \(i\) Supplier \(4i+1\) Legal child keys
0 1 \(\{-1\}\)
1 5 \(\{5\}\)
2 9 \([7,9]\)

The first two rows force slope 6 and intercept \(-1\). At the third input that line gives 11. Every pair of rows admits an integer line, for example \(4i-1\) on states 0 and 2 and \(2i+3\) on states 1 and 2. One minimum of two lines serves all three states,

\[ k_{\rm child}=\min(6i-1,4i+1). \]

At each state this interval contains the supplier and excludes the guard for every opening. Both the base branch and the surviving recursive branch return \(4i+1\), which lies in every permitted parent interval. This proves the same local obligation at every recursive depth. The clients can choose the interval ending at \(4i+1\). Supplying the minimum explicitly or splitting on the three constructors before the call both verify and execute at budget 2. Four observations characterize failure of an affine witness

Let each history \(h\) have an integer observation \(x_h\) and a closed range of keys \([L_h,U_h]\) with finite integer endpoints. One integer-affine policy works on every history if and only if one works on every subset of at most four histories. This also holds for infinitely many histories. For finite families the upper bound is an instance of the lattice Helly theorem in the two integer coordinates \((m,c)\). The interval structure gives a direct proof, a way to compute the policy, and a sharp example using actual package constraints. Doignon · Lattice bound · Formal proof

For \(x_h<x_j\), set \(d=x_j-x_h\). The two rows admit a common intercept at an integer slope \(m\) precisely when both rows are nonempty and \[ \left\lceil\frac{L_j-U_h}{d}\right\rceil \le m \le \left\lfloor\frac{U_j-L_h}{d}\right\rfloor . \] If every four histories fit, any two of these closed slope intervals meet. Even in an infinite family, the integer intervals have a common point. Indeed, any one upper endpoint bounds all their lower endpoints, which therefore attain a maximum. Histories with the same observation impose the slope-independent checks \(L_h\le U_j\). For a slope satisfying all pairs, the intervals \([L_h-mx_h,U_h-mx_h]\) have a common integer intercept by the same argument. If all observations coincide, take slope zero. For \(n\) explicit rows the compiler intersects \(n^2\) slope inequalities and then takes the largest adjusted lower endpoint as the intercept. This step finds a policy whenever the rows admit one and its coefficients fit the term representation. Inferring the rows and checking the rest of the program are separate obligations. Shared-intercept criterion

\(-2\) \([-5,0]\)

\(1\) \([1,5]\)

The rows at \(-2\) and 1 force \(3m\ge1\). The rows at \(-1\) and 2 force \(3m\le2\). No integer slope meets both. Omitting the rows in table order gives the respective witnesses \(1\), \(x\), \(0\), and \(x+1\). Each row is realizable with the same package width 7, supplier \(U_h\), and a single forbidden value \(L_h-1\).
