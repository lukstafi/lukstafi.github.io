**Theorem.** With arbitrary specified read permissions, leading validity of a *supplied* equational answer is NP-complete on every nontrivial finite-signature term algebra. Even two public universal inputs and a matrix of variable equalities suffice for hardness. For synthesis with an empty premise, arbitrary carrier permissions give a decidable one-branch problem. The upper bound is NP for idempotent substitution answers, including the atomwise escape tests. Round 37 extends the polynomial certificate to arbitrary weak presentations with an empty premise. [Two-stage compression](round-37-comparable.html)

Here a carrier is an original game move whose *value* a substitution term is allowed to use. Round 31 handles unrestricted witnesses, along with the usual prefix-closed permissions, even for a nonempty premise. This round allows a witness to read an existential carrier while omitting the universal names that the carrier can see. [General-premise theorem](round-31-leading.html)

## Checking a supplied answer by generation of terms

Give each universally chosen game move \(h\) its own new rigid letter \(r_h\), including leading fresh parameters. For an existential move \(e\), its game value \(G_e\) is any term built from original constructors and earlier rigid letters. Set \(G_h=r_h\). A nonsubstituted name has ordinary value \(V_x=G_x\). For \(x\) substituted in validity, its ordinary value \(V_x\) must be built from original constructors and the *whole* game values \(G_z\) of its permitted names \(z\). Require the supplied answer equations \(A(V)\) to hold in this enlarged ground algebra. In particular a substituted name used by another witness supplies its original game value, exactly as required by simultaneous substitution.

These requirements are equivalent to validity. Given witness terms, the remaining quantified conjunction of equations admits existential term strategies whenever its prefix game is true. Evaluating them over independent letters gives the \(G\)'s and then the \(V\)'s. Conversely a term construction for each \(V_x\) supplies its witness, and the constructions of the \(G_e\)'s supply its plays. Replacing the independent letters by any ground inputs proves validity. The singleton original algebra is immediate. [Term criterion for a quantified conjunction](round-18-signature-boundary.html#parameter-free-quantifier-prefixes)

The resulting constraints are equations and tests that a value belongs to the algebra generated by a list of values using the original constructors. They have polynomial-size ground DAG solutions whenever satisfiable. In a solution mark all values at explicit constructor nodes in the equations, and all rigid letters. Keep the root and recurse at each marked value; send every other value to an original base constant. Evaluation of each explicit expression commutes with this transformation. A construction from a set of generators is preserved: a generator still maps to its image, an omitted constructor maps to the available base, and retained constructors can rebuild their children. The transformed terms share a node for each marked value plus the base. Check generation bottom up on this graph. [Lean proof of both preservation statements](round-29-generators.lean)

The [decision procedure](round-32-carriers.py) guesses for every residual value either the base or a pointer to an explicit constructor node or rigid letter. Finite-tree unification checks the pointers, and the generator tests decide each resulting assignment. Conversely the compression just described supplies such pointers for every successful solution. It suffices to count syntax nodes as a DAG; writing out the expanded values can take much longer.

## NP-hardness of the read permissions

Take a 3-CNF formula. Use universal moves \(h_0,h_1\), and for each Boolean variable \(p\) two existential carriers \(e_p^+,e_p^-\) after both universals. Introduce two substituted coordinates per variable, with answer equations requiring one to equal \(h_0\) and the other \(h_1\). Each of those two witnesses can read only \(e_p^+,e_p^-\). For each clause introduce a substituted coordinate required to equal \(h_1\). Its witness can read only the carriers named by its literals. Quantify the substituted coordinates existentially after the carriers. [Karp, satisfiability with at most three literals per clause](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf)

A satisfying assignment makes each literal carrier copy the universal for its Boolean value. For the clause witness choose one true literal's carrier. Conversely an original constructor term producing a bare rigid letter must read a generator equal to that letter. The two carriers of each variable must therefore take opposite letters, and every clause must see the true letter. This recovers an assignment. This argument uses independent *formal* letters for the two universals, and works even in an algebra with just two ground constants.

The reduction is also a synthesis lower bound for \(\top\Rightarrow C\) under the weak check or the original reflexive strong order. Its displayed \(C\) is already an idempotent substitution, its left coordinates are later existentials, and each atom is individually prefix-valid. Any answer implies \(C\) on every ordinary row, so its validity witnesses give validity of \(C\) itself after fixing fresh names. Conversely a valid \(C\) is the answer. The same equivalence holds for any supplied conclusion that is itself an admissible presentation.

For the *extracted* strong order, place the substituted request coordinates in an initial existential block before the two universals instead. Each request atom then has its sole universal strictly later than its designated head, so both extracted escape tests pass. The request's original game move is unused. The carrier choices and Boolean argument are identical.

### One forbidden read on a binary signature

On $\{f/2,a\}$, supplied-answer validity and empty-premise synthesis are NP-hard even with a **single substituted coordinate $K$**, a **single universal $r$**, and all reads permitted except $K$ reading $r$. Use the prefix $\exists t_1\cdots t_n,K\,\forall r\,\exists (E_{j,l})$. The $t_i$ choose ground values before $r$. Use two distinct ground truth values $a,b$ (for example $b=f(a,a)$) and distinct ground clause identifiers $q_j$. The target cell of clause $j$ is

$$ T_j=f(r,f(q_j,f(a,b))). $$

Require $K$ to equal the ordinary binary list of all $T_j$, with cells $f(T_j,\mathrm{tail})$ and terminator $a$. For each occurrence of a positive literal $i$ in clause $j$, define its carrier to be $E_{j,l}=f(r,f(q_j,f(t_i,b)))$. For a negative occurrence use $E_{j,l}=f(r,f(q_j,f(a,t_i)))$. The answer is an idempotent substitution. $K$ has its sole universal later than its left side. All carrier definitions are individually prefix-valid. Hence it passes both extracted escape tests.

A satisfying assignment plays $t_i=a$ for true and $t_i=b$ for false. In each clause choose a true literal and use its carrier as the corresponding list cell's payload in the witness for $K$. Conversely play the universal as a rigid letter. All accessible game values except the carriers are ground over the original signature. Each carrier has that bare letter as its left child. A nonempty list node has a compound left child containing the letter, so no generator can supply a whole such node. The witness must construct the list spine. At a target cell it cannot separately construct the bare letter, so it must use a whole carrier. Its clause identifier must agree, and matching its last pair requires $t_i=a$ for a positive literal or $t_i=b$ for a negative one. Assign the corresponding truth values, extending arbitrarily on variables with other ground values. Every clause has a true literal. The same argument applies to $\top\Rightarrow C$ where $C$ is this supplied answer: any valid answer entails $C$, and when $C$ is valid it is itself admissible. With unrestricted reads, checking supplied-answer validity is polynomial by the unifier criterion of Round 31. [Single missing read with a nonempty premise](round-34-one-read.html)

On monadic signatures a fixed number of witnesses with non-closed permissions admits polynomial-time supplied-answer verification, even if each such witness has many possible carriers. [Suffix algorithm](round-41-monadic-reads.html)

## An empty premise with arbitrary atomwise permissions

For an arbitrary successful answer to \(\top\Rightarrow C\), eliminate fresh names as in Round 31. Use the generic validity tuple \(V\) above as the common witness, in the term algebra extended by the rigid letters. It satisfies all ordinary answer equations. The unifier of those equations makes \(C\) identically true because ordinary relevance holds in the nontrivial original algebra.

Select at most \(|X|\) primitives \(x=t\) with parent-atom scope records as in Round 31. Apply the witness-path compression to the unification of these primitives. Distinguish the values of the ordinary coordinates \(V_x\), original game moves \(G_x\), the rigid letters, and all subterms of \(C\) at \(V\). Fix the roots of explicit constructors of \(C\) and the rigid letters. Retain the pivot paths and one path per required input occurrence. The compressed primitives still imply \(C\) by replay. They have a validity tuple consisting of the compressed \(V_x\). Indeed apply the same transformation to each original witness *body* over game names, using the assignment of the \(G_x\). Its root and every game-name value are distinguished. Projection commutes with evaluating this body and introduces no new names. The compressed \(G_e\)'s still contain only earlier letters, and the compressed \(G_h\)'s remain their letters. No rigid symbol is written into an ordinary answer or a witness body: a raw term attaining a bare rigid letter at its witness must itself be a variable. Instantiating the letters back to original ground trees also gives ordinary consistency. [Substitution identity and path replay](round-28-compression.html)

Support retention and padding preserve the original escape checks. There are polynomially many distinguished values and recorded paths, giving polynomial depth and a singly exponential expanded answer. Guessing that answer and using the supplied-answer validity test puts this case in NEXP.

## A polynomial bound for solved presentations with empty premise

Unify \(C\) over the public coordinates and write its normal forms \(L_x(Z)\). Reject an inconsistent \(C\). Guess the unbound public names \(U\) of a proposed idempotent answer. All its coordinate patterns have the form \(P_x=L_x[N_z(U)/z]\), because they must unify \(C\). For \(u\in U\), \(L_u\) must be a residual name \(z_u\) with \(N_{z_u}=u\); the \(z_u\)'s are distinct. Guess the exact support of each unknown term \(N_z\) in \(U\). This determines every public occurrence set in the presentation \(x=P_x\) for \(x\notin U\). If escape uses an individual-validity exemption requiring a bare later existential, enforce that bare copy in the corresponding \(N_z\); a constructor-rooted \(L_x\) cannot supply it. The other exemptions and the strong test are determined by the occurrence sets. [Individual validity test](round-31-leading.html#solved-presentations-have-polynomial-certificates)

Introduce \(M_z=N_z(V_U)\) in the enlarged ground algebra and put \(V_x=L_x(M)\). For a prescribed bare \(N_z=u\), set \(M_z=V_u\) and use that stipulated body. For every other \(z\), require that \(M_z\) be generated from the named \(V_u\)'s with precisely the guessed support. Add the game-value and witness-generation constraints of the first section. These conditions are sufficient: take any realizing \(N_z\)'s and validity witnesses, and build the stated solved presentation. The formal identity \(P_u=u\) holds, \(C(P)\) is an identity, and the reconstructed atoms meet the scope tests. Necessity follows by evaluating a successful presentation at its generic validity tuple.

**Exact supports still admit polynomial certificates.** In a solution distinguish the values of all syntax nodes in the equations and generator tests, including all generator names' values, the target values and the rigid letters. For each required occurrence in each construction, record one path from its target to that named generator. There are polynomially many paths. Apply the distinguished-value compression with these paths and all explicitly required constructor roots. At a free root pack the selected children, at a fixed root retain the original constructor. Evaluating a compressed construction gives its compressed target by the substitution identity, and the designated occurrences of its generators survive. This also works when two different generator names have identical values. The compressed ground values share a polynomial-size DAG and the retained occurrences have polynomial depth. In each compressed body keep one path for every required generator and fill the remaining pieces by ordinary generation using only the allowed names, memoizing per target node. This yields polynomial-size DAGs for exact-support constructions as well. Equations, prefix scopes and all tests can now be verified in NP.

The executable compares the supplied-answer checker with direct finite games and tests the SAT reduction. The synthesis upper bounds in the last two sections are written proofs. They use the empty premise to make the generic validity row available for the ordinary argument. A nonempty premise can exclude that row. With the extracted strong rule, a single nonempty premise can check an independent evaluation and yield r.e.-complete existence. [One branch and one carrier](round-33-carrier-reduction.html)
