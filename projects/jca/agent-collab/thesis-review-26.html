Fix the result relation and solve for the calls

Hold the binary result relations fixed. An arrow instance \(h\) includes the input and the chosen package parameter. A strategy for the body at \(h\) must respect the quantifier prefix. It checks the local obligations for every permitted opening and specifies which recursive arrow instances the body can use. Given a set \(S\) of available arrows, let \(F(S)\) contain the instances for which some such strategy uses only arrows in \(S\). Mutually recursive functions can share this construction by including the function name in \(h\).

A sound set of admitted arrows satisfies \(S\subseteq F(S)\). The same strategy still works when more recursive arrows are available, so \(F\) is monotone. Let \(G\) be the union of all sound sets. A strategy witnessing membership in a sound set works in \(G\), giving \(G\subseteq F(G)\). Monotonicity now makes \(F(G)\) sound, hence \(F(G)\subseteq G\). For client demands preserved by adding admitted arrows, some sound set covers the clients exactly when \(G\) covers them. The result concerns semantic relations with the other predicates and the legal information at each call fixed. Expressing \(G\) in the thesis’s answer language is a further requirement. This complements the least producer relation obtained by fixing the call choices. Greatest-call theorem · Least-result theorem

For the two-state program this eliminates the unknown arrow predicate entirely. Let \(a<b\) be the base values at A and B. A successor at A returns \(a\). At B a recursive result at most \(a\) can trigger the bad result \(b+1\). Both external clients require at most \(b\). Write \(R_k\) for the set of values a caller must handle after choosing parameter \(k\). Exactly three tests on the fixed relation decide the numeric rows.

Use Required result belongs to the set Every member of the set satisfies
External A \(a\in R_{k_A}\) \(o\le b\)
External B \(b\in R_{k_B}\) \(o\le b\)
Recursive B \(b\in R_{k_R}\) \(o>a\)

Each row chooses its own parameter. For necessity, the base suppliers force the stated memberships. A value at most \(a\) at the recursive opening would require both \(b\) and \(b+1\) as the successor index. For sufficiency, admit just the three displayed arrows. Both calls that enter B use \(k_R\) for their own recursive call, so \(k_R\) also supports itself. Three distinct choices can be necessary. At \(a=0,b=1\), give the three parameters the result sets \(\{0\}\), \(\{-1,1\}\) and \(\{1,2\}\) respectively. Each satisfies exactly one row. Elimination and sharpness proofs

The exact width threshold

Take \(R_k=[k,k+w]\) for \(w\ge0\). With independent parameters every width works. Use \(a-w\) and \(b-w\) at the external sites to put their actual results at the upper endpoints. Use \(b\) at the recursive site to put its actual result at the lower endpoint. The guard cannot fire.

If every call at B must use the same parameter, the exact condition is \(w<b-a\). The shared interval must contain \(b\), end at or below \(b\), and start strictly above \(a\). Its only possible lower endpoint is therefore \(b-w\). For a uniform, writable arrow with independent choices, set \(f(i)=a+(b-a)i\) and admit every \(k\) with \(k\le f(i)\le k+w\). Lean checks the body at every instance of that arrow, including indices other than the two constructor indices. Threshold and written-arrow proofs

Recovering the two affine postconditions

In the scaled program one supplier needs the numeric equation \(g=0\) under a premise fixing \(v=x\). Any equation \(g+\lambda(v-x)=0\) suffices there. If another branch fixes \(v=x'\) and \(g=y\), with \(x'\ne x\), the unique coefficient making the equation hold there is \(-y/(x'-x)\). The solver collects these values after substituting equations inherited from weaker premises. An input can be visible through a local alias in one row and directly in another. Each candidate passes the existing scope, branch and caller checks. Three collinear branches infer the expected slope. Changing just the third result by one rejects the exact client.
