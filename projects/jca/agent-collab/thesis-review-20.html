A call that every typing must admit

Let \(Q\) be the original quantifier prefix, \(F\) the facts known about the branch, and \(G\) the entire guard of a call. A strategy chooses existential witnesses using only the universal moves already visible. A play follows that strategy for one sequence of universal moves. Call a strategy legal when \(F\) holds on every one of its plays. Assume there is a legal strategy. Then the following statements are equivalent.

  1. Every legal strategy has a play on which \(G\) holds.
  2. \(Q.(F\land\neg G)\) is false.
  3. \(\bar Q.(F\Rightarrow G)\) is true, where \(\bar Q\) exchanges the quantifiers in place.

A strategy winning \(F\land\neg G\) is precisely a legal strategy that avoids the call on every play. Negating this statement gives the first equivalence. Quantifier duality gives the second. The Lean proof allows the domain of each move to depend on previous moves. Proof of both equivalences

For example, under \(\exists x\,\forall y\), the guard \(x=y\) occurs on some play of every strategy. Whatever \(x\) the strategy picks, the opponent can match it. Under \(\forall y\,\exists x\), the strategy \(x=y+1\) can avoid the guard. Testing satisfiability after erasing the prefix would give the same answer to both queries.

A candidate input pattern must overlap the instantiated arguments at each such site. Take the play supplied by the theorem. The original call obligation puts its argument in the candidate domain. Different sites may obtain their witnesses on different plays and at different instances of the candidate type. For a fixed argument this recovers the argument itself. A call with a varying argument can warrant just one instance. Admitting every public instance takes the stronger coverage condition from the earlier review. The solver uses overlap to guide term abduction, then checks the original clauses. Lean overlap lemma · Public argument coverage

The same theorem applies to a family of sites offering one fixed argument \(t\). Use \(G=\bigvee_i G_i\). If every legal strategy must reach some site, the domain must admit \(t\), even when every individual site has an avoiding strategy. For instance, let the original prefix be \(\exists n\) and put the same call under \(n\le0\) and \(0\le n\). Choosing 1 avoids the first, choosing \(-1\) avoids the second, and no choice avoids both. This is a further source of required input instances beyond the implementation’s per-site test. Common-argument theorem and two-site example

Patterns, numeric guards and witness order

A constructor match can determine how to interpret a later test. Suppose an earlier test \(H\) entails an equation \(e\). Simplify the remaining test \(J\) using \(e\), obtaining \(J'\). Under the facts, \(H\land J\) is equivalent to \(H\land J'\). Keeping \(H\) in the accumulated guard is essential. Taking \(H\) to be false and \(J'\) to be true already shows what goes wrong if the earlier test disappears. InvarGenT processes premises contained in the guard in order of size and retains the tests that licensed each rewrite. This covers nested constructor matches, including a GADT witness, and a constructor with two hidden indices and guard \(m+1\le n\). Guarded rewrite proof · Compiler examples

The dual game can share an index between the type and arithmetic components. Consider \(\exists a\,\forall n\,\exists k.\ a=\mathrm{Num}(k)\land k=n\). It is false. Choosing the type \(a\) also fixes the enclosed index before \(n\) is known. Moving \(n\) before \(a\) makes the same matrix true. In general, a proposed value for a type witness can be chosen at its move exactly when it is constant on plays with the same visible history. The implementation checks a sufficient condition on the variables of the solved term. When all remaining numeric moves belong to the witness player, it can fix their joint values in advance. Witness factorization lemma

A numeric subproblem exposed an independent error. The conjunction \(x\le0,\ y\le0,\ 1\le\max(x,y)\) has no solution. InvarGenT previously returned a feasible state, even though its implication check could prove a contradiction from that state. The satisfiability routine now chooses one arm from each unresolved alternative and checks their joint linear system. It stops at the first feasible combination and returns the original state so later constraints can still choose another arm. A source constructor with these three constraints now allows assert false in its match arm. Relaxing \(x\le0\) to \(x\le1\) makes the arm possible, and the assertion is rejected.
