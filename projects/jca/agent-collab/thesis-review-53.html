Take the type indices Base and Step a, represented by the GADT values Root and Next x. A recursive function accepts Root, fails on Next Root, and strips two constructors from any longer argument. Every call terminates. The safe inputs have exactly the even depths. No finite Boolean combination of equational patterns on this input expresses its safe domain. This gives a boundary for the closure of term guards under sequential composition.

What a public guard can say about one index

On the represented indices \(S^n B\), a single unary pattern is empty, a singleton depth, or a tail containing all depths at least \(k\). A pattern matching a represented index must be a chain of successors ending at its base or at a hole. Projecting private equational witnesses gives a pattern of the same kind.

Consequently, finite Boolean combinations of unary patterns express exactly the eventually constant depth predicates. Beyond all the constructor depths in a finite formula, every singleton test is false and every tail test is true. Conversely, take all the accepted singleton depths below a cutoff and add the tail if all later depths are accepted. In particular, any such guard that excludes every odd depth can admit only finitely many even depths. Lean theorems expressible and even_inexpressible

What happens during recursive checking

Write \(D\) for the currently permitted depths. Rechecking the three arms gives \[ F(D)=\{0\}\cup\{n+2\mid n\in D\}. \] The first arm always succeeds. The second always fails. The third demands permission for its child call. Starting from all depths, after \(t\) rechecks the candidate consists of all evens and all depths at least \(2t\). The next round removes \(2t+1\). Every finite round changes the candidate, and their intersection is exactly the evens. This is the descending semantic recheck for the greatest safe domain. An inductive safe contract only requires \(D\subseteq F(D)\). In particular, the singleton \(\{0\}\) suffices if the base is the sole mandatory input. Requiring depth \(2m\) forces admission of \(2m-2,\ldots,2,0\) as well. Each safe positive pattern can cover at most one of these depths. Exactly \(m+1\) conjunctive alternatives suffice: take those \(m+1\) singleton patterns as the admitted union and check recursive calls against that union. Already the safe call at depth two belongs to no inductive single-pattern domain. More generally every nonempty inductive domain expressible by a finite Boolean guard is an initial segment of the even depths. Each has a strictly larger expressible inductive extension. A decision for finite control, and an indexed witness

Suppose the recursive computation has a finite control state \(q\). Reading a successor transfers to \(\delta(q)\) on the child. At the base a fixed Boolean \(b(q)\) decides success. At depth \(n\) the verdict is \(b(\delta^n(q))\). Follow the orbit from the chosen initial state to its first repeated state. The states before the repeat give a finite prefix followed by a nonempty cycle.

The exact public domain has a finite Boolean term guard iff all states on that cycle have the same verdict. With a uniform verdict the prefix and the eventual truth value construct the guard. With a mixed cycle both verdicts recur arbitrarily late, which violates eventual constancy. This decides whether this guard language can express the exact answer, including for a recursive procedure whose visible index grows without bound across possible calls. There is also a constructive way to pass the missing information. Declare a GADT OK(q,a). For each accepting state give a nullary constructor of type OK(q,Base). For every state give a constructor taking OK(δ(q),a) to OK(q,Step a). Induction on the represented depth shows that a finite constructor value of this type exists exactly when the computation accepts. For a fixed initial state and depth, the outer constructor is forced at every step. This encoding introduces an explicit value argument at the program interface. An existential quantifier over equational type variables alone would still project to an ordinary pattern.

For even depth, two constructors suffice: ERoot : Even Base and EPair : Even a ⟶ Even (Step (Step a)).
