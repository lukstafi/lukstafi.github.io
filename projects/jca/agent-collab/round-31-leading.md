**Theorem.** One equational implication under the leading-fresh convention is decidable with designated variables and unrestricted substitution witnesses. This includes the weak atomwise escape test. If answers must be idempotent substitutions, the problem is NP-complete over every nontrivial fixed finite single-sorted signature with a constant, including with the strong test and with both tests together. For arbitrary conjunctive presentations with the weak test the proof below gives an NEXP upper bound. A second compression using comparable substitutions sharpens this to NP-completeness. [Polynomial certificates for weak presentations](round-37-comparable.html) Ground-only witnesses and witnesses restricted to earlier moves are covered as well.

The read permissions needed for the result are specified below. The scope relation used in the *escape test* can be supplied separately, including either comparison on prefix positions in the thesis materials. Two branches are already r.e.-complete on branching signatures with the designated set empty. ## Which inputs can a substitution witness observe?

Use \(X\) for the original public coordinates, \(T\) for the ones simultaneously substituted in validity, \(K\) for the designated names in the escape test, and \(B\) for fresh answer names. Keep ordinary relevance and consistency on the original public coordinates. Leading validity asks for terms \(t_j\) such that \(\forall B\,Q.\,A[T:=t]\) holds. Each term has a specified set of names it may use. The universal moves of \(Q\) outside \(T\) are the **retained inputs** \(H\).

First eliminate fresh names in a one-branch existence proof. Choose their ground values from a joint witness of \(A\land D\) and specialize them in the answer and the validity witnesses. Leading validity held at every such choice. Relevance survives restriction, and the chosen row still supplies consistency. Public occurrence sets of surviving atoms are unchanged. An individually valid atom remains individually valid after specialization. For an idempotent substitution, first delete any definition whose left side is fresh: its left name occurs nowhere else, so dropping it preserves the ordinary public projection and weakens the validity obligation. Specialize fresh names in any remaining witness terms as well. All surviving definitions now have public left sides and still form an idempotent substitution.

For \(j\in T\), let \(J_j\subseteq H\) be the retained universal names directly permitted in \(t_j\). Assume that whenever an existential move \(e\) is permitted in \(t_j\), every retained universal preceding \(e\) is in \(J_j\). This condition holds for unrestricted witnesses, for any set of universal names alone, and for permissions consisting of a prefix of the moves. It allows the witness term to mention other substituted names, whose values there are their original game moves. For a retained existential \(x\), let \(J_x\) be precisely its preceding retained inputs.

**Validity criterion.** Unify a satisfiable fresh-free \(A\), writing \(P_x(U)\) for its idempotent normal forms in its unbound public coordinates \(U\). Then validity holds precisely when

- \(P_h=u_h\) for distinct bare names \(u_h\in U\), for all \(h\in H\);
- for every \(x\in X\setminus H\), the only names \(u_h\) occurring in \(P_x\) have \(h\in J_x\).

For necessity, fix the successful witness terms. The remaining validity matrix is a conjunction of equations. Its prefix game has a term strategy for each existential move in earlier universal names, by the tuple-pattern criterion. Specialize original universal moves in \(T\) to constants. This gives a tuple of ordinary \(A\)-values over distinct rigid letters for \(H\), with each retained universal equal to its own letter. A retained existential value contains only preceding letters. A substituted value contains only letters in \(J_j\): an existential it reads could receive only preceding letters, all directly permitted by the assumption. The ordinary tuple is an instance of \(P(U)\); the only way a coordinate can instantiate to a single rigid letter is for it to be a bare parameter. Its letter survives at every coordinate containing that parameter. [Prefix pattern criterion](round-18-signature-boundary.html#parameter-free-quantifier-prefixes)

Conversely substitute the public input \(h\) for each \(u_h\) and one ground constant for all other residuals. The resulting \(P_x\) are permissible plays for retained existentials and permissible witness terms for substituted coordinates. The original moves in \(T\) can be ignored. The resulting ordinary tuple satisfies \(A\) identically. The singleton algebra admits the empty answer.

## Solved presentations have polynomial certificates

Guess the unbound public set \(U\) of an idempotent answer. Its atoms are \(x=P_x(U)\) for \(x\notin U\), and \(P_u=u\). Guess the distinct universal representatives \(u_h\) and the exact set of leaves used by each body. The validity criterion checks which \(u_h\) can occur. The occurrence sets also decide the syntactic escape tests. For the weak exemption one needs individual validity of \(x=t\), with \(x\) absent from \(t\). If \(x\) is existential, this holds when every universal in \(t\) precedes \(x\). If \(x\) is universal, \(t\) must be a bare later existential. The latter follows by varying \(x\) with earlier moves fixed and using the different available root choices. A bare later existential can copy \(x\).

For the ordinary branch the names \(U\) are independent input variables and every defined coordinate is a body in its declared leaves. A forced alias \(P_h=u_h\) is inserted directly in \(D,C\); this also deals with identities of unbound public coordinates. For individual validity, retain any required bare-copy shape directly. The remaining task is the one-branch strategy problem with prescribed input sets and prescribed occurrence of each selected input.

The [polynomial DAG argument](round-29-small-dags.html) works with these requirements. Scope there is used only through the allowed leaves of each body. In its first compression, record one path to an occurrence of every selected input in each body alongside the unification paths. The root and endpoint values are distinguished, adding at most \(|X|^2\) paths. Each still visits at most linearly many distinguished values. Depth stays polynomial. In the second compression explicitly retain one such occurrence in each shallow body fragment. Reconstructing the other fragments uses subsets of their original leaves. Exact supports therefore survive, and the size bound remains polynomial. Individual validity of a permissible existential-left equation survives retaining its support, and a universal-left exemption uses the fixed bare copy. The resulting ordinary graph presents an idempotent solution passing all tests. Checking it requires only polynomial DAG operations. Taking \(K=T=\varnothing\) gives the NP lower bound. ## Arbitrary weak presentations can be shortened before verification

An unrestricted conjunction can express a chain of dependencies through public names. Solving the whole conjunction syntactically may put previously separated names together and change the escape test. The following construction keeps an admissible presentation.

At a joint witness, decompose each original answer equality through common constructor heads, discard identities, and orient each remaining primitive as \(x=t\). Select a subfamily incrementally: whenever the currently selected equations fail to entail some original primitive, add that primitive. Its addition binds at least one further residual name in a consistent unification, so at most \(|X|\) primitives suffice. The resulting conjunction is equivalent to the answer.

For each selected primitive record the public variable set of its parent atom. If the parent passed the weak test by its variable set, that set can be restored on a branching signature by packing the primitive with identical copies of the recorded names on the two sides of an equality. Equality in a free term algebra makes this padding logically inert. If the parent passed by individual validity, it entails the primitive, so that primitive is individually valid as well. On monadic signatures a nonidentity primitive already has its parent's variable set because cancellation removes only unary prefixes. No padding is needed there.

Now fix the ground joint witness \(W\) on all public names. Use the [witness compression](round-28-compression.html) with two consecutive groups of equations. Unify the selected answer primitives **first**, and then continue with the actual premise \(D\). Every pivot is taken at the same witness \(W\); there are at most \(|X|\) in total. Distinguish the values of all public names and all subterms of \(D,C\), keeping the explicitly written constructor roots of \(D,C\). Each unknown primitive right side has distinguished root value \(W_x\). Record one path for each input occurrence that needs to survive, as above.

Let \(\pi\) be the resulting transformation. Replace every primitive \(x=t\) by \(x=\pi(t)\). The first group of recorded pivots gives **an mgu of the shortened answer alone**. Indeed each transformed pivot is forced by replay of the previous pivots in this group. Conversely those bindings make all its equations identities by the substitution identity for \(\pi\). Each binds its same left-hand name to a term containing neither that name nor a previously eliminated name. Therefore the original unbound names are still free, and the normal form of each coordinate is \(\pi(P_x)\). Every bare retained alias is unchanged and no new input name appears. The validity criterion survives.

The remaining pivots certify relevance of the shortened answer in the presence of \(D\), exactly as in Round 28. The transformed witness supplies consistency. The individually valid exemptions for primitives survive the support restriction or bare copy as above. Restore the padding on the other primitives to recover the original atomwise permissions. There are polynomially many retained paths and distinguished values, so the resulting answer has polynomial depth and at most singly exponential expanded size on a fixed signature. Enumerating such answers is finite. Nondeterministically guessing one and verifying it gives the stated NEXP bound.

## Checks and boundary of the result

The [executable checks](round-31-leading.py) compare the validity criterion to direct quantification over legal witness terms and all game plays in the two-constant algebra. They also replay a binary answer unifier before a premise binding, and check preservation of an input occurrence unnecessary for ordinary relevance. The shared-DAG and witness compressors have an option to preserve supports. [Substitution lemma for the compressor](round-28-projection.lean)

The read-permission condition has content. With \(\forall h\,\exists e\,\forall k\), substitute for \(k\) and take \(A=(e=h\land k=h)\). If the only allowed name in the witness for \(k\) is \(e\), the witness \(k:=e\) works: \(e\) carries the value of \(h\). Ground witnesses fail. A check that looked only at directly permitted universal names would therefore be unsound for such permissions. For arbitrary individual read permissions, checking a supplied answer is NP-complete. One nonempty premise already gives r.e.-complete existence under the extracted strong rule, even when only one read by one witness is forbidden.
