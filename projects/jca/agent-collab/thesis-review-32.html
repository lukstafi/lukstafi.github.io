A recursive call must still have a key

Fix the observed inputs. Let \([L,U]\) be the nonempty range of legal integer keys and \([k+A,k+B]\) the promised result interval, with \(A\le B\). All four bounds may depend on the inputs. A nonempty result band \([l,u]\) forbids exactly the keys \([l-B,u-A]\). For one band, try \(U\) if \(U+A>u\) and \(L\) otherwise. If some legal interval fits to the right, \(U\) fits. If none fits to the right, any legal interval fitting to the left can be replaced by \(L\). The rule always supplies a legal key, including when every legal opening can hit the guard. Endpoint and coverage proofs

Coverage matters even for a single constructor. Add a state \(s=0\) and call the function at width zero. Its only legal key is zero, and its only result is zero. Strengthening the call premise with “the interval avoids zero” makes the guard vacuously unreachable by eliminating the call. A total selector supplies zero here. The original guard is then reachable, and InvarGenT rejects the definition. It also rejects a call that sends a valid parent state to the zero child and a client that demands the wrong result sign. A bound on choosing the key

With \(m\) nonempty bands, start at \(x=U\) and visit each forbidden key band \([a,b]\). If \(a\le x\le b\), move to \(a-1\). Every move preserves every safe candidate below the current point. A full sweep either stays put at a safe key or passes at least one lower endpoint that can never be crossed again. After at most \(m\) sweeps the point \(p\) is the greatest safe integer at most \(U\). Returning \(\max(L,p)\) preserves the legal domain and is safe whenever any legal key is safe. The argument works pointwise when input-dependent bands exchange order. It bounds the work of selecting a witness for a fixed package. Lean proof by counting lower endpoints · Two guards whose order changes

Descending order of lower endpoints gives one sweep. There is another one-sweep case even when sorting would require branching on the inputs. If \(U+A\le L+B\), every legal package contains the common point \(f=U+A\). For each nonempty result band with \(u\ge f\), any feasible interval must lie strictly to its left. Cap the key at \(l-B-1\). For every remaining band, a feasible interval must lie strictly to its right, since it contains \(f>u\). Taking the greatest key under all the caps preserves these right-hand exclusions whenever a feasible key exists. The compiler tests the common-point inequality under the written premise. Empty result bands impose no restriction. Single-pass anchor theorem

InvarGenT encodes the choices using existing numeric constraints. For example, it compares \(U+A\) with \(u+\tfrac12\). On integer inputs that test selects precisely one of the two endpoints. On a rational tie the graph permits the whole interval, which preserves coverage in the numeric checker. The proposal requires integral affine endpoints. A range \(2k\in[1,3]\) illustrates the risk of selecting a fractional endpoint when the integer key must be 1. Additional constraints on the key can disconnect its domain. Two call sites need two choices

Call run s width d twice with identical arguments. The first opening must exclude zero. The second must exclude \(-2\). At \(s=-1\) and any positive integer width \(n\), the legal keys run from \(-1-n\) to \(-1\). Excluding zero forces the first key to be \(-1-n\). Excluding \(-2\) forces the second to be \(-1\). Each call has a witness. No shared key works. At \(s=1\), both can choose \(1\). Two-site program · Incompatibility proof

Both instantiations have constant-size descriptions. For the first, the ordinary call premise together with \(k+n\le-1\lor 1\le k\) suffices. For the second, \(k=s\) suffices. Every opening of each selected package meets its own guard obligation.

What the erased key tells us about the result

One can type the two-site program without choosing a different interval at each opening. The key \(k\) has no runtime argument. Fix a terminating execution at the other arguments and let \(r\) be its observable result. If the definition meets its contract for every admitted \(k\), the same \(r\) belongs to every corresponding result set. Private witnesses for an opening can still vary with \(k\). In symbols, the conclusion is \(\forall k\in K.\,\exists w.\,R(k,r,w)\). To use the rule, one needs a common runtime input admitted at every one of those keys. Quantifiers and projection

For translated intervals the intersection has a closed form,

\[ \bigcap_{L\le k\le U}[k+A,k+B]=[U+A,L+B]. \]

The two extreme keys give the necessary bounds. Every other interval contains their intersection. Here \(L=s-n\), \(U=s\), \(A=0\) and \(B=n\), so the result is exactly \(s\). Writing that result in the postcondition makes the two-site program check and execute at budget 2. Adding \(r=s\) alongside the original two inequalities also works, at budget 3. The base case returns \(s\), and the recursive hypothesis excludes both guarded branches, leaving the same result in the step case. This gives a constant-size inductive solution for the original interval specification.
