A counterexample at every outer budget

Use the states A : State 0 and B : State 1. At depth zero, run observes 0 at A and 4 at B with an index-preserving external function. At positive depth it returns 0 at A. At B it opens a recursive call at B, returning 5 if the result is at most 0 and returning 4 otherwise. Both external clients require at most 4. The exact scheme \(\forall i.\,\mathsf{State}(i)\to\mathsf{Nat}\to\exists().\,\mathsf{Num}(4i)\) checks and executes. The recursive result at B is 4, so the branch returning 5 cannot fire.

With the default component settings at a3151c0, no outer budget succeeds. At budget zero the solver times out after the first update on both available attempts. At budget one, each of the six attempts completes pass 0, enters pass 1 and returns a numeric abduction failure. There are no discard retries. On this path the outer budget is tested only on the successful pass-0 update. The pass-1 failure exits before the next budget test, and the next attempt is selected from the failure kind. Thus replacing one by any larger budget follows the same six paths. The traces at 1, 11 and 10,000 agree event for event. This refutes a convergence guarantee even under a constant bound large enough to admit the displayed solution. Program · Pass trace and controls

The coefficient search and the iteration budget control different decisions. Increasing -postcond_rotations alone from 3 to 4 still fails. Increasing -num_abduction_rotations alone to 4 infers a valid scheme and executes both clients. With base results 0 and 5, radius 4 again fails and radius 5 succeeds. What the binary postcondition describes

Write \(i\) for the state index, \(k\) for the parameter chosen at a call, and \(o\) for the hidden index of the number found when the result is opened. The binary predicate \(R(k,o)\) tells the caller which results to handle at its chosen \(k\). The unary predicate on the function’s arrow determines which choices of \(k\) the function admits at \(i\). Each use may instantiate that arrow. A call fixes \(k\) before seeing its result.

In the shifted program the base case returns 1 at A and 2 at B. A successor at A returns 1. At B it opens a recursive call at B, returns 3 if the result is at most 1, and otherwise returns 2. Both external clients require at most 2. One solution chooses \(k=i\) everywhere and sets \(o=k+1\). The dangerous branch is then unreachable.

Here is a second solution, using exactly the interval InvarGenT proposes on a full pass. Admit the arrows with \(k\le i\le k+1\) and give each one the postcondition \(k+1\le o\le k+2\). The definition must verify every admitted arrow. At either state its actual result \(i+1\) belongs to that interval. The following instantiations establish the recursive step and the external bounds.

Call State index \(i\) Chosen \(k\) What the opening guarantees
External call at A 0 0 \(1\le o\le2\)
External call at B 1 0 \(1\le o\le2\)
Recursive call at B 1 1 \(2\le o\le3\), so the guard \(o\le1\) fails

The two choices at B are necessary for this interval. Suppose all calls there have the same \(k\). The external client requires every \(o\) at \(k\) to be at most 2. The recursive guard requires every such \(o\) to exceed 1, since the guard would otherwise require the successor result to have both indices 2 and 3 in the joined typing obligations. The base case requires 2 to be present. Over the integers the relation at \(k\) must therefore be exactly \(\{2\}\). No interval \([k+1,k+2]\) has this property. InvarGenT accepts and executes the two-choice scheme written above and rejects the same interval with \(k\) tied to the input. Sufficiency and necessity · Both written interfaces

What the iteration does

For an offset \(z\), replacing an opening relation by \(R'(k,o)=R(k,o-z)\) transports every solution of the unshifted numeric rows to the shifted rows. Translating back gives the inverse. This preserves legal pre-observation choices, recursive openings, the declared observation, and both clients. An exact solution for every offset is \(o=k+z\) with \(k=i\). A relation that forgets \(k\) cannot solve these rows for any offset. Its base at A puts \(z\) into the relation, where the recursive call at B can see it. Translation and parameter-necessity proofs

At offset 1 the solver infers the exact local match type \(\mathsf{State}(i)\to\mathsf{Num}(i+1)\). With the default jump threshold the final search attempt makes these binary updates on passes 4 through 40.

On an even pass the upper endpoint at B is 3. Abduction can ensure the client bound by requiring \(i\le0\), which excludes its call at B. On an odd pass the caller again demands \(o\le2\), but the empty tuple loses the distinction needed by the recursive guard. With the default threshold 8, no numeric jump runs in the recorded passes. Moving the threshold to 3 runs the jump on passes 3 and 4 and yields the same alternation from pass 5 onward. There is an exact semantic criterion for introducing this helper with the other predicates fixed. Let \(d\) range over legal definition histories, \(c\) over legal call histories, and \(a\) over candidate arrow instances. At an available observation \(v\), allow \(a\) precisely when the body checks at \(a\) for every \(d\) with that observation. This gives the largest safe helper relation.
