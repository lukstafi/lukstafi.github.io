title: "JCA Round 26: A fixed pair of implications can recognize a machine language"
date: 2026-11-21
---

**Theorem.** Fix a recursively enumerable language \(L\) over a finite alphabet. There are two ordinary JCA implications over \(\{f/2,a/0\}\), with one ground-subtree position left blank, and an injective linear-size encoding \(w\mapsto b(w)\) such that filling the blank with \(b(w)\) gives an answer exactly when \(w\in L\). Each implication has one equality on each side. One can choose the blank in a premise, or use a second fixed pair with the blank in a conclusion.

In particular, choosing a machine for the halting problem gives an r.e.-complete problem even with a fixed number of public variables. Both premises can be fixed in advance. Alternatively, both conclusions can be fixed in advance. In each version, three of the four equalities are fixed and the fourth varies at one position.

## A fixed source with an input word

For a fixed machine \(M\) recognizing \(L\), Veanes constructs a fixed simultaneous rigid \(E\)-unification system \(S_M(z,x,y)\) with ground hypotheses. A word \(w\) is accepted exactly when the system has a ground solution in which \(z=\bar w\). Here \(\bar w\) is the right-associated word tree with a fixed terminator. All letters, states and other constants used by \(M\) form a finite alphabet of constructors with one binary operation. Veanes's forward witnesses use this alphabet. Restricting to it preserves the converse because any such solution is also a solution in the larger language of the report. [Veanes, Theorem 5.2.1 and Corollaries 5.2.2–3](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/upmail0126.pdf#page=22)

Keep \(z\) in the fixed system and append **one** rigid constraint with empty hypotheses. Its goal is \(z=\bar w\) for the premise placement and \(\bar w=z\) for the conclusion placement. Empty hypotheses test literal equality. Either orientation pins \(z\) to the input word. The system, including its last color index \(k\), all declared constants, and all three data variable names is now fixed apart from this one literal.

## Following the literal to the target

Round 24 copies the constants of each rigid constraint into its private color and packs all starts into one tuple and all targets into another. Thus precisely one tuple contains \(\bar w^k\), the word in the color of the appended constraint. The type and synchronization goals refer only to copies of the data variables. The three sets of ground hypotheses are fixed. [Coloring reduction](round-24-two-branches.html#converting-arbitrary-ground-hypotheses-to-two-chains)

Fix the symbol order of the binary encoder once for this finite alphabet. Its term encoding \(e\) uses every child exactly once. The binary code \(b(w)=e(\bar w^k)\) is therefore an injective linear-size encoding. The alphabet, tags and wrapper count are fixed, so each new letter adds a fixed one-hole context around the encoded suffix. The set of word codes is itself a regular tree language, generated by the terminator code and these finitely many contexts.

*Blank in a premise.* When the goal is \(z=\bar w\), the word occurs on the target side of the colored goal tuple. In the binary reduction this tuple appears in the list-end template of the first proof. Its only occurrence in the output instance is the patched value of a single slot in the marker-row premise. The patch changes a leaf of the outer tag, disjoint from the encoded target below it. Neither the other slot nor the checking row mentions the template. The single occurrence of \(b(w)\) survives.

*Blank in a conclusion.* With the reversed goal \(\bar w=z\), the word occurs on the start side of that tuple. The checking-row conclusion prepends the encoded start to the proof tail. Every target, hypothesis template, protected-coordinate list and marker is fixed. The marker-row conclusion just equates the two proof coordinates. Hence the encoded start contributes one occurrence of \(b(w)\) in a conclusion and none in either premise.

Packing term lists into equalities copies each side of each original atom once. Both placements therefore survive the final packing. All public coordinates come from the fixed colored data tuple, three proof pairs, and two slots for each of the fixed hypothesis-side and list-end templates. The choice of \(w\) changes none of these coordinates. Soundness for arbitrary answers and completeness for each input follow from the binary reduction. [Binary reduction](round-25-binary.html)

## Verification

The [executable check](round-26-fixed-template.py) uses a small fixed system accepting exactly the words made entirely of the letter \(b\). It locates the changed subtree by comparing packed instances for the empty word and \(b\). It then fills that same position for all 15 words of length at most three over \(\{b,c\}\) and compares each result against a fresh compilation, for each placement. It also checks source membership by ground congruence closure and verifies full JCA certificates on all eight positive instances across the two placements. The arbitrary-language result uses Veanes's theorem and the occurrence argument above.
