What a recursive call has to choose

Suppose a function at state \(i\) supplies the integer \(4i+1\) and promises a result in \([k,k+2]\). Its caller may choose any \(k\) whose interval contains \(4i+1\). Inside the recursive body, the child needs an interval that also misses a guard. For the forbidden band \([2,4]\), the possible child keys at states 0, 1 and 2 are \(\{-1\}\), \(\{5\}\) and \([7,9]\). One affine function cannot fit all three. InvarGenT now infers \(k_{\rm child}=\min(6i-1,7)\) and checks the unsplit program at iteration budget 2. The emitted OCaml calls run s d. Three-state source · Single-line obstruction

There is an exact test for when a minimum of any finite number of integer-affine lines can work. Let observation \(h\) require the key at \(x_h\) to lie in a fixed integer interval \([L_h,U_h]\). Every line in the minimum must lie above every \(L_h\). To meet the upper bound at observation \(j\), one such line must also lie below \(U_j\) there. Translating that line up until it meets \(U_j\) gives the following slope test.

\[ \text{For each } j\text{ there is an }m_j\in\mathbb Z \text{ such that } m_j(x_j-x_h)\le U_j-L_h\quad\text{for every }h. \]

If the test passes, the lines \(x\mapsto m_j(x-x_j)+U_j\) give a witness. For fixed \(j\), each other observation imposes an upper or lower integer bound on \(m_j\), or a slope-independent test when the coordinates coincide. If the bounds have empty intersection, at most two of them suffice to show it. Thus on a finite set of observations, every triple admits a minimum if and only if the whole set does. Repeated observations cover sets of size one or two. The bound is sharp. Take the exact values 5, 7, 13 at coordinates 1, 2, 3. Each pair lies on an integer line. At the middle coordinate a supporting line would need slope at most 2 and at least 6. Negating the intervals gives the dual test for maxima. Lean proofs of the criterion and sharpness · Four observations for a single line

The compiler first tries the single affine line. For a minimum it considers the observations in increasing order. It fits one line to the longest initial block of upper bounds it can cover while clearing all lower bounds, then starts a new block. An active line in a pointwise minimum is active on an interval, since comparison with each competitor cuts out a half-line or the whole domain. With ties assigned in slope order, an optimal envelope therefore partitions the observations into consecutive blocks. Extending its first block to the greedy endpoint leaves a suffix of the original partition. Repeating gives the fewest lines on the supplied rows. Computing the slope bounds for a new upper endpoint costs one scan over the lower endpoints, so the fit takes \(O(n^2)\) arithmetic operations on \(n\) rows.

Four states require both changes of slope

Add a fourth state and forbid \([10,12]\) as well as \([2,4]\). The permissible child keys are now singletons.

State Supplier Child key Child interval
0 1 \(-1\) \([-1,1]\)
1 5 5 \([5,7]\)
2 9 7 \([7,9]\)
3 13 13 \([13,15]\)

The successive slopes are 6, 2 and 6. A minimum of lines has nonincreasing slopes, and a maximum has nondecreasing slopes. Neither can fit the table. With \(v_+=\max(0,v)\), one expression serves all four states,

\[ k_{\rm child}(i)=6i-1-4(i-1)_+ +4(i-2)_+ . \]

Each change in slope contributes its coefficient times a positive part. Across an integer gap of length \(d\) with a rise of \(a\), write \(a=md+r\) with \(0\le r<d\). Use slope \(m\) for the first \(d-r\) units and \(m+1\) for the last \(r\). This also works for a negative rise. Joining consecutive observations gives every finite table on distinct integer inputs an expression with linearly many terms. A private witness can hide a public precondition

The first three-state experiment also exposed a bad exported type. It occurs on the unmodified compiler at 3eb191e. Give the function an extra numeric argument \(l\) and write \(k=\min(l,4i+1)\) and \(k\le4i+1\le k+2\) in its precondition. Every result must lie in \([k,k+2]\). At \(i=0\), \(l=-3\), the upper bound on the supplier would require \(1\le-1\). The old public signature lost this bound. The compiler accepted a client calling run A (-3) Z and passing its result to a function requiring a nonpositive number. The base case returns 1. A witness can depend on two arguments together

Give the function two independent states \(i,j\in\{0,1\}\) and let the supplier return \(f=4(i+j)+1\). The recursive result must again miss \([2,4]\). Fix \(i=0\). At \(j=0\) the only possible child key is \(-1\). At \(j=1\) it is 5. So no function of \(i\) alone works, however large its expression. Holding \(j=0\) rules out a function of \(j\) alone. The joint witness

\[ k_{\rm child}=\min\bigl(6(i+j)-1,\;4(i+j)+1\bigr) \]

satisfies all four input pairs. Its interval contains the supplier and avoids the forbidden guard for every permitted opening. The base and surviving step branches both return \(f\), which every legal parent interval contains. The same argument thus works at every recursion depth.
